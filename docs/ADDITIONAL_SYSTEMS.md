# ママゲー（仮題） 追加システムリスト v1.0

> 2026-07 の設計ディスカッションで確定した追加システムのまとめ。
> 目的：完全独立抽選で失われる「デッキ圧縮・カウント」系の戦略深度を、**盤面の位置関係**で補う。
> 方針：Backpack Battles の「毎ラウンドの編集量は1〜2個」「配置そのものが遊び」を踏襲し、劣化版StS化を回避する。

---

## 0. 設計原則（全システム共通）

1. **戦闘報酬は「ピース1個を選んで置く」で完結**させる（編集10秒）。既存配置の移動は自由だが、動かさなくても成立するバランスにする。
2. **フル組み直しは「決断」の瞬間に集中**させる（レアピース入手・盤面拡張・合成成立など）。毎戦闘後の作業にはしない。
3. 手札のカードは常に**出身ピースの盤面位置を参照できる**（位置参照カードの土台。実装の大前提）。
4. UIは システムと同じ優先度：隣接バフの受給状況・回路の接続をビルド画面で一目で可視化（ハイライト／接続線）。戦闘中は盤面ミニマップで該当ピースを光らせる。

## 1. 基本システム（テーマ非依存・最初に実装）

### 1-A. 盤面拡張（5×5 → 10×10）
- ラン開始時は **5×5＝25マス**。ショップ・イベント・報酬で区画を購入し、最大 **10×10＝100マス** まで拡張。
- 拡張は「どの区画を買うか」の**ドラフト**にする（区画に特殊マスが混ざる。§1-B）。
- **広さと濃度のトレードオフ**を明示する：拡張すると総マス数が増え、既存ピースの占有率（＝ドロー確率）が相対的に薄まる。「狭く濃い盤面」か「広く多彩な盤面」かが戦略軸。
- 表記の整合：出現率は常に「占有マス数 ÷ 現在の総マス数」。空白マスは通常攻撃に変換（既存仕様を維持）。

### 1-B. 特殊マス
- 拡張区画・イベント報酬に混在する、効果付きのマス。
- 例：
  - **増幅マス**：覆ったピースのカード威力 +50%
  - **呪いマス**：覆うとデメリット／空けておくと通常攻撃に変換
  - **点火マス**：覆ったピースは毎戦闘開始時に点火状態（§3参照）
- 特殊マスの位置が「ここに何を置くか」という配置パズルの起点になる。

### 1-C. ピース合成（レシピ）
- 特定の2ピースを**隣接配置した状態で戦闘をN回**こなすと、上位ピースに融合する。
- 融合後のピースは元の2つの合計より**小さい形**になる（盤面圧縮）。「融合でスペースを空けて次を仕込む」進行リズムを作る。
- 明示レシピ（図鑑掲載）と隠しレシピ（発見要素）の2層。リプレイ性・実績・コミュニティ攻略の核。
- 例：短剣＋毒壺 → 毒刃（形は3マスに圧縮、毒付与つき攻撃）

## 2. 位置参照カードシステム（戦闘中に配置が効く・独自性の核）

### キーワード定義
- **連結X**：このカードの出身ピースに**隣接**するピースを対象に効果X
- **回路**：このターン、盤面上で隣接し合うピース由来のカードを**連続プレイ**している状態
- **点火**：ピースに付くマーク。次ターンの抽選で重みが大幅に増加（PRDの重み操作と統合実装）

### テーマ（アーキタイプ）
StS のキャラ／カラー相当。プレイヤーが選択・混成できるビルドテーマとして、位置参照カードを系統別に分類する。

| テーマ | 配置思想 | 核となる動き |
|---|---|---|
| **密集（オーラ）** | ピースを固めて置く | 隣接バフの授受を最大化。旧①隣接バフ案はこのテーマに統合 |
| **伸長（回路）** | 細長く道を作る | 回路の長さを参照するペイオフ |
| **柱（行・列）** | 縦横一列に揃える | 同列ピース数を参照する大技 |
| **点火（エンジン）** | 点火の連鎖網を張る | 抽選重み操作でドローを支配する |

### キーカード案（数値は仮）

**エンジン始動系**
- **導火線**（コスト1・アタック）：ダメージ6。連結：隣接ピース1つに点火。
- **狼煙**（コスト0・スキル）：カードを1枚捨てる。捨てたカードの出身ピースに隣接する全ピースに点火。
- **呼び水**（コスト1・スキル）：連結：隣接ピースの中から1枚、即座に手札に加える。

**ペイオフ系**
- **電流**（コスト1・アタック）：ダメージ4。回路中なら回路の長さ×3を追加。〔伸長〕
- **共鳴**（コスト2・アタック）：ダメージ8。連結：隣接する攻撃ピース1つにつき+4。〔密集〕
- **雷落とし**（コスト3・アタック）：出身ピースと同じ列にある全ピース数×5ダメージ。〔柱〕

**防御・安定系**
- **隊列**（コスト1・スキル）：防御5。連結：隣接ピースが防御系なら防御を倍にする。〔密集〕
- **橋渡し**（コスト0・スキル）：このターン、離れた2つのピースを「隣接している」とみなす。〔汎用〕

**変則・レア枠**
- **震脚**（コスト2・スキル）：出身ピースを盤面上で1マス移動させる（戦闘中のみ）。
- **女王蜂**（コスト2・パワー）：このバトル中、点火したピースのカードはコスト-1。〔点火〕

### オーラ専用ピース（密集テーマの拡張）
- 盤面を占有するが**ドロー抽選には入らない**ピース。隣接ピースへの常時パッシブのみを提供。
- 「合計ドロー率を下げてでも常時効果を取るか」のトレードオフ。「占有率＝確率」の看板と整合。

## 3. 実装優先度

| 段階 | 内容 | 検証したいこと |
|---|---|---|
| **第1陣（プロトMVP）** | 隣接バフ（密集テーマの基礎）＋ 導火線・呼び水・電流・共鳴の4枚 | 「回路をなぞる楽しさ」「隣接配置の思考」が成立するか |
| **第2陣** | 点火系（PRD重み操作と統合）、盤面拡張ドラフト、特殊マス | 拡張の意思決定が面白いか、点火エンジンが回るか |
| **第3陣** | 合成レシピ、柱テーマ、オーラ専用ピース、震脚などレア枠 | リプレイ性・ビルド多様性 |

- 実装面：yoshiki のイベントフック購読型設計に **OnAdjacencyCheck**（隣接判定）系フックを追加すれば第1陣は成立する見込み。
- 第1陣が面白くなければ、第2陣以降を足しても救えない。判断はここで行う。

---

## 4. バランス・UI上の注意

- 隣接シナジー導入で「占有率＝ドロー確率」のシンプルさに情報量が乗る。**ビルド画面での可視化**（バフ受給ハイライト・回路接続線）をシステムと同格で設計する。
- 回路・連結の発動時、戦闘画面の隅に盤面ミニマップを表示して該当ピースを発光させる（ドット絵映え・実況映えを兼ねる）。
- 密集／伸長／柱／点火は同じピースプールでも配置哲学で別ビルドになる構造を守る（BBの「同じアイテムでも組み方が違う」の再現）。
